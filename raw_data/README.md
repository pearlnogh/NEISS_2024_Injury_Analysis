## Raw Data

This project uses the 2024 National Electronic Injury Surveillance System (NEISS) annual dataset provided by the U.S. Consumer Product Safety Commission.

Due to file size considerations, the raw data file is not included in this repository.

### Data Source
- U.S. Consumer Product Safety Commission
- National Electronic Injury Surveillance System (NEISS)
- Dataset: Archived Annual NEISS Data (2024)
- File format: Excel

### Access Link
https://www.cpsc.gov/cgibin/NEISSQuery/home.aspx

### Download Instructions
1. Visit the NEISS Data and Query Builder page
2. You will see a **User Affiliation (Required)** selection (Media, Consumer, Researcher, Industry, Other). You can choose **Media** or any option, as this does not affect the raw dataset content.
3. Scroll to **Archived Annual NEISS Data**
4. Select:
   - Year: 2024  
   - File Format: Excel
5. Download the file labeled **"neiss2024 - MS - Excel"**
6. Rename the file to:

   `neiss_2024_raw.xlsx`

7. Place the file in the `raw_data/` directory

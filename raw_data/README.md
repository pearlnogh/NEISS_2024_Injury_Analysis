## Raw Data

This project uses the **2024 National Electronic Injury Surveillance System (NEISS) annual dataset**
provided by the U.S. Consumer Product Safety Commission (CPSC).

Due to file size considerations, the raw data file is **not included** in this repository.

### Data Source
- U.S. Consumer Product Safety Commission (CPSC)
- National Electronic Injury Surveillance System (NEISS)
- Dataset: Archived Annual NEISS Data (2024)
- File format: Excel

### Access Link
https://www.cpsc.gov/cgibin/NEISSQuery/home.aspx

### Download Instructions
1. Visit the NEISS Data and Query Builder page
2. Scroll to **Archived Annual NEISS Data**
3. Select:
   - Year: 2024  
   - File Format: Excel
4. Download the file labeled **"neiss2024 - MS - Excel"**
5. Rename the file to:

   `neiss_2024_raw.xlsx`

6. Place the file in the `raw_data/` directory
